# Warga Baladewa Raya — Prototipe awal

Ini adalah prototipe antarmuka (demo) untuk aplikasi warga.

## Penting
- Seluruh angka, status iuran, agenda, dan pesan adalah data contoh.
- Login, database online, sinkronisasi antarperangkat, live chat nyata, unggah foto, dan ekspor laporan belum diaktifkan.
- Jangan gunakan demo ini untuk menyimpan data kas asli atau PIN warga.
- Sebelum dipakai sungguhan, sambungkan backend dan siapkan autentikasi serta aturan keamanan database.

## Isi
- `index.html`: prototipe satu halaman yang responsif untuk HP dan desktop.
